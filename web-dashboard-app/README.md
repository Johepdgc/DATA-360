# Web Dashboard de Quejas

Esta aplicación muestra dashboards interactivos de quejas categorizadas a partir de un archivo CSV.

## Características
- Gráfico de barras de quejas por motivo.
- Tabla detallada de comentarios filtrados por categoría.
- Filtros adicionales (fecha, plataforma, región) a futuro.
- Diseño moderno con Tailwind CSS y Recharts.

## Cómo correr la app

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
